# Episode I — curated visual reference set 07: helmets II

Internal art library only.

## Equipment progression

- **Common:** leather hoods, padded caps, simple riveted helmets and basic kettle helmets.
- **Rare:** mail aventails, practical visors, plumes, wrapped hoods and factional trim.
- **Epic / named:** ornate crests, animal motifs, horned or masked designs, but only when tied to a clear item trait or faction.
- **Legendary:** luminous gems, severe ceremonial masks and singular silhouettes; these should be unique, not routine drops.

## Selection rule

Prioritize believable face openings, neck coverage and one readable silhouette. Reject ornament that hides the helmet's construction or makes a human head impossible. The elaborate masks are valuable visual directions, but most do not belong in early Episode I loot.
